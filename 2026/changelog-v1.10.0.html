v1.10.0

Released on: Wed Nov 18 17:05:31 2026 +0000

  • [PR #19862][kubevirt-bot] Bump libvirtxml to v1.12007.0 and fix the smmuv3 IOMMU ssidsize attribute, so Grace IOVirtualization VMIs get their SSID size and keep their IOMMU driver attributes when guest definition plugin hooks run.
  • [PR #19771][kubevirt-bot] Fix VMIs with SR-IOV, GPU or PCI host devices failing to start when the Plugins feature gate is enabled and any Plugin exists in the cluster.
  • [PR #19863][kubevirt-bot] Node hooks now fall back to the Plugin-level failureStrategy when they do not set their own, like launcher hooks. Plugins with spec.failureStrategy: Ignore no longer block VM start, stop or migration when one of their node hooks without its own failureStrategy fails.
  • [PR #19743][kubevirt-bot] Fixed a virt-handler panic when a device plugin is restarted, which on nodes with host devices happened on every kubelet restart.
  • [PR #19732][stu-gott] Live migrations are no longer scheduled from a node running an updated virt-handler onto a node that has not yet been updated, preventing migrations from getting stuck during a rolling upgrade.
  • [PR #19690][kubevirt-bot] Beta: IncrementalBackup, and introduce backup.kubevirt.io/v1beta1
  • [PR #19688][kubevirt-bot] CBT overlays are now keyed by volume and PVC name. Pointing a volume at a different PVC triggers a Full backup instead of an incorrect incremental.
  • [PR #19294][alromeros] Offline incremental backup
  • [PR #19492][caxu-rh] Fixed a bug that caused a gRPC connection to leak when virt-handler client initialization fails
  • [PR #19574][noamasu] Guest writes are recovered when a VM starts after a virt-launcher crash during an External mode snapshot.
  • [PR #19360][noamasu] VEP 321: add External mode VirtualMachineSnapshot
  • [PR #19485][0xFelix] Exported OCI archives now contain the Image Index as a blob referenced from index.json with ref.name “latest”, so pushing them creates an Image Index in the registry
  • [PR #19550][Acedus] Memory dumps are attached as utility volumes and require the UtilityVolumes feature gate, which is promoted to Beta and enabled by default. VM snapshots and exports no longer include the memory dump PVC.
  • [PR #19056][Acedus] VirtualMachineBackup no longer fails when a disk has lost the base checkpoint’s bitmap; that disk is backed up in full and type is now reported per volume in status.includedVolumes[].type, replacing the removed status.type.
  • [PR #19511][nirdothan] NetworkDevicesWithDRA Feature Gate is now in Beta stage
  • [PR #17135][lyarwood] Add Alpha UEFI Secure Boot support for ARM64 guests through the ARM64SecureBoot and FirmwareAutoSelection feature gates. Requires CentOS Stream 10 virt-launcher images with suitable QEMU, libvirt, and edk2 firmware. Supports persistent EFI state through existing backend storage.
  • [PR #19590][lyarwood] Build KubeVirt with go 1.26.10
  • [PR #19066][0xFelix] The io.kubevirt.disk.name annotation of exported OCI artifacts now carries the volume name from the VM instead of the PersistentVolumeClaim name
  • [PR #19228][Sreeja1725] Alpha: Add CPUsWithDRA to provision dedicated VMI CPUs via a DRA CPU driver instead of kubelet’s CPU manager.
  • [PR #19572][orelmisan] The pod-status VMI network interface info source is now reported for interfaces whose device is ready in the pod (DRA-backed, and Multus-backed secondary interfaces), when the NetworkDevicesWithDRA feature gate is enabled.
  • [PR #19173][alromeros] Declarative VirtualMachineState
  • [PR #19410][Acedus] HostDisk volumes are no longer eligible for changed block tracking.
  • [PR #19520][noamasu] Use a memory-backed emptyDir for the hotplug mount root to support mount propagation.
  • [PR #19435][awels] Cleanup CBT overlays when disabling CBT
  • [PR #19382][mhenriks] ContainerPath volumes graduate to beta
  • [PR #19240][vladikr] virt-launcher-monitor is rewritten in C to reduce memory footprint to about 2Mi
  • [PR #19064][0xFelix] Fixed a bug where a VirtualMachineExport of a VM with two claims whose names differ only in dots would never complete
  • [PR #18249][dsanatar] IOThread Virtqueue Mapping for virtio-scsi

  • [PR #19534][caxu-rh] Fixed a bug where a Unix socket listener may be left open if an error occurs while setting file ownership on the socket
  • [PR #19490][awels] Only add virt-handler migration identity to synchronization controller if proxy is enabled.

  • [PR #19409][Acedus] Live migration of CBT-enabled VMs creates the target’s CBT overlays from the source’s domain, and unplugging a volume removes its CBT overlay regardless of the VMI’s CBT state.

  • [PR #18753][orelmisan] Fix SSRF vulnerability (CVE-2026-13318) in virt-api port-forward that allowed a malicious QEMU guest agent to redirect virtctl port-forward and ssh traffic to arbitrary network endpoints. virt-api now dials only the launcher pod IP and never the guest-agent-reported interface IP.
